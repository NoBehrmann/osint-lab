STATUS CHANGES (Oct 2026)
- OpenCorporates  API now needs a token
- Etherscan       needs a key, use Blockscout instead
- Blockchair      blacklists keyless callers
- OTX             passive_dns needs a key; general + url_list still keyless
- GreyNoise       community endpoint keyless (low quota)
- abuse.ch APIs   need a free Auth-Key, bulk feeds still keyless
- BGPView, ThreatMiner, PhishTank feed, columbus.elmasy: dead
- Reddit JSON     403 for anonymous clients
- Holehe          last update Sep 2024, see user-scanner
- Blackbird       moved to antoniaci/blackbird, quiet since Jul 2025
- h8mail          stale since 2023, mostly paid backends
- Mailcat         rejected: probes mailboxes over SMTP (not passive)
